# MoviesHub - REST API для управления фильмами

## Простой REST API
Встроенный HTTP сервер Java без внешних фреймворков
Полный CRUD для управления фильмами
JSON формат запросов и ответов

## Основные возможности
Добавление новых фильмов с валидацией
Просмотр списка всех фильмов
Поиск фильма по ID
Сортировка фильмов по названию
Удаление фильмов

## Стандартные HTTP методы
GET - получение данных
POST - создание новых записей
DELETE - удаление записей
Корректные HTTP статусы ответов

## Чистая архитектура
Отдельные слои для обработки HTTP, бизнес-логики и хранения
In-memory хранилище для быстрой работы
Полное покрытие тестами API endpoints

# Технологии

## Java 17
## Встроенный HTTP Server
## GSON 2.8.9 для работы с JSON
## JUnit 5 для тестирования
